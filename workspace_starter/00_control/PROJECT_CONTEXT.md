# Постоянный контекст

## Подтверждено владельцем
- Windows 10 x64; OpenCode и ZCode — целевые локальные оболочки. Версии и возможности ещё не установлены.
- Цель: освоить источники/инструменты/skills/готовые workflows, широко исследовать спрос и выбрать около 5–7 обоснованных ниш для множества тематических каналов на разных языках.
- Никакая ниша, платформа, язык, TTS-провайдер или модель монетизации ещё не назначены победителями. Любая законная монетизация рассматривается, реклама не обязательный приоритет.
- Владелец лично проверяет English/Russian/Ukrainian/Greek. Для других языков naturalness не считается подтверждённой переводом/ASR.
- Есть навыки технологий, аудио, OBS, стриминга и монтажа; есть монтажные/ASR/alignment/audio-analysis инструменты. Точные названия/версии/железо неизвестны. Не заменять рабочий стек без инвентаризации.
- Планируется собственный cloud voice clone, собственные записи/демонстрации/оригинальные материалы. Провайдер и права/условия требуют выбора.
- GLM 5.3 Flash упоминалась как возможный вариант: точный model ID, доступ и качество не проверены.
- Новый Deep Research не является зависимостью. Не тратить исследовательский запуск на переписывание плана.

## Неизвестно
Бюджеты, установленные версии/модели/провайдеры, shell permissions, MCP/skill paths, browser/version, способы auth, hardware, конкретные программы, целевые публикационные аккаунты. Уточнять по мере необходимости, а не анкетой обо всём до начала работы.
