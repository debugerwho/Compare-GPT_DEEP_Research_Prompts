# Разбор экспорта «Вайб-кодинг»: июль — 8 ноября 2026

Проверено 8 ноября 2026. [Папка источника в Drive](https://drive.google.com/drive/folders/1u8YsQZSB33PF4X8EzpQ4WlULONjTnbzl).

## Что сохранено

- **[115 карточек кандидатов](TOOL_CANDIDATES.md)**: отдельные инструменты, community skills, наборы, готовые workflows, reference-проекты и явно отделённый discovery backlog. Некоторые карточки объединяют связанные plugins; это **не 115 проверенных рабочих программ**.
- [Машиночитаемые карточки](tool_candidates.json): этапы, тип, роль, посты/даты/ссылки, происхождение находки, статус, Windows-ограничения и риски.
- [Индекс всех 849 сообщений](post_index.jsonl): ID, исходная дата, краткое начало текста, ссылки, пути фотографий и связь с отобранными карточками. Полные тексты сообщества не перепубликовывались.
- [Проверки 83 GitHub repositories](github_checks.json): у **82** доступны metadata и README; `cheahjs/free-llm-api-resources` вернул 404. Записаны README blob SHA, license detection и сведения репозитория. Это не аудит исходников или установка.
- [Отдельно прочитанные документы](documentation_checks.json): четыре README DAIR plugins, `define-goal/SKILL.md`, исходники страницы/теста OpenCode Browse.
- [Происхождение HTML и семи просмотренных фотографий](source_manifest.json): Drive IDs, SHA-256, размеры, связанные посты, результаты визуальной проверки.
- **[Последовательные сравнительные пробы](TRIALS.md)** — без назначенного победителя, без новой зависимости от Deep Research.

## Границы полноты — существенны

Извлечены **849 сообщений**, из них **701 с непустым текстом**, **487 ссылок на фотографии**. Первичный тематический фильтр дал 288 кандидатов; отбор дополнен просмотром ссылок, целевых постов и README. В карточках непосредственно использованы **79 разных постов**; дополнительные находки внутри marketplace/README помечены отдельно.

Это широкий первый проход по архиву, **не доказательство, что все полезные сведения из каждого изображения уже найдены**. Полный ручной аудит всех 849 сообщений не проводился. **121 сообщение только с фотографиями** не просмотрено целиком; визуально рассмотрены семь целевых изображений. Нельзя утверждать, что остальные фотографии не содержат полезного. У фотографий сохранена принадлежность из export; не приписывали текст соседнего поста по догадке. Видео, помеченные экспортом `Not included`, отсутствуют и не просмотрены.

Metadata/README скачаны у 82 upstream, но не все README полностью прочитаны вручную. Подробно проверялись ключевые режимы доступа, зависимости и риски приоритетных кандидатов; у остальных статус ограничен проверкой существования и описания. **Ни один runtime на компьютере владельца, MCP-конфиг, GLM или платный аккаунт не испытан.**

Исходные даты экспортированы как `UTC-08:00`; они сохранены без подмены часовым поясом владельца. Свежесть дат постов не оспаривается. Проверка правдивости заявления и его дата — разные вопросы. Текущий README может описывать уже другую версию, чем июльский пост.

## Что действительно добавилось к проекту

### 1. Готовые процедуры, не только очередные браузеры

**First Customer Finder**, пост [3478](https://t.me/vibecoding_tg/3478): собирает публичные причины, по которым конкретным людям может быть нужен продукт. Полезен как пример evidence-driven pain discovery: факт → источник → причина интереса → альтернативное объяснение. Это ещё не поиск 5–7 лучших тематических ниш и не доказанные покупатели. README: Node для installer, Python 3.9+ helpers, исходно Codex с web/browser; специфический API key самого skill не требуется. Расходы оболочки/платформ остаются.

**Agent Reach**, [3613](https://t.me/vibecoding_tg/3613): готовый слой доступа к разным платформам. В README обнаружены важные ограничения: отдельные logins/cookies, экспериментальные пути, Groq/OpenAI для некоторых ASR-сценариев. Проект предупреждает, что PyPI-тёзка `agent-reach` ему не принадлежит; нельзя слепо устанавливать совпавшее имя. Заявление поста «бесплатный доступ ко всему интернету» не принимается буквально.

**X Agent Intelligence / DAIR**, [3539](https://t.me/vibecoding_tg/3539): готовая локальная лента с короткими summaries и ссылками, источники выбирает пользователь. README говорит об official X MCP и auth, но сам по себе MIT-код не предоставляет X API/тариф. Scheduler не включён. Можно изучить как workflow регулярной разведки; подбор AI-аккаунтов не превращать в границы всех будущих ниш.

В указанном **DAIR marketplace** найдены дополнительные готовые компоненты:

- **Wiki Builder**: `raw/`, `wiki/`, `derived/`, `sources.md`, `wiki.config.md`, журнал изменений. Особенно полезен как кандидат для постоянного контекста исследования. Не нужно немедленно переносить туда весь репозиторий: сначала одна проверка ingest → synthesis → provenance → contradiction/update.
- **YouTube Notetaker**: video → слайды с таймкодами + transcript + редактируемые Markdown-заметки + небольшой локальный viewer. Зависит от yt-dlp, FFmpeg, Python и shell scripts; их работа на Windows/в выбранной оболочке отдельно проверяется.
- **Survey Generator**: HTML-обзор из research bundle и библиографии, затем Fireworks API. Наличие красивого отчёта не означает, что поиск и проверку источников выполнил сам генератор.
- Ещё image/lesson/learn/LLM-council plugins: оставлены как пакет вспомогательных возможностей, не обязательные элементы.

### 2. OpenCode и ZCode теперь имеют более конкретные точки проверки

**OpenCode Browse**, [4294](https://t.me/vibecoding_tg/4294): через исходники сайта OpenCode найден upstream [anomalyco/browse](https://github.com/anomalyco/browse), README прочитан. Это MCP server + Chromium extension, настоящий профиль браузера, pairing, tabs/screenshots/network/screen capture и передача управления человеку для login/2FA. Windows install документирован; npx-путь требует Node 22.19+. Автообновления включены по описанному default и управляются пользователем — версии/настройку учитывать в воспроизводимости. Пригодность для установленного ZCode не предполагается, а проверяется отдельно.

**BrowserSkill**, [3873](https://t.me/vibecoding_tg/3873): CLI/daemon для Windows x64, README прямо указывает Windows 10/11, Chrome/Edge Chromium 125+. Есть agent window/borrow tabs, отдельные правила remote operation и сохранения наблюдений. Captured bodies/fields, screenshots и `save-full` могут содержать личные данные. Это сильный кандидат на сравнение с Browse/agent-browser/Playwright, а не победитель заранее.

**ZCode**, [3904](https://t.me/vibecoding_tg/3904): установлен первичный repo [zai-org/ZCode](https://github.com/zai-org/ZCode), README доступен; в `.agents/skills` видны agent-browser и другие skills. Это не доказывает, что пользовательский desktop build имеет те же функции, конфиг и квоты. Ссылку на repo больше не нужно запрашивать у владельца.

Пост утверждает, что Repo Wiki отправляла workspace с `.git`, а версия 3.14.0 удалила функцию. **Ни обвинение, ни исправление независимо не подтверждены в этом проходе**: внешняя публикация не прочитана, patch/data flow не аудированы. Фотография показывает только GitHub homepage. Практический вывод: проверить точную установленную версию, настройки индексации/снимков, разрешения и исходящие обращения на тестовом каталоге без секретов. Не обвинять актуальную версию без доказательств и не считать её безопасной только из-за open source.

### 3. Чтение реального содержания, а не доверие заголовкам

**claude-video**, [3581](https://t.me/vibecoding_tg/3581), позволяет извлекать captions, кадры и таймкоды. Его текущий README различает local engine и Gemini engine: последний может передавать видео в облако. Пример «добавить ключ в чат» из upstream не повторяется — только локальное secret storage. Анализ ограниченного числа кадров не доказательство просмотра всего ролика.

**.MD this page / Jina Reader / OpenDataLoader PDF / anydoc** — разные классы чтения, не взаимозаменяемые названия. Выбор зависит от страницы, PDF, таблицы, captions и возможности сохранить provenance. Заявления «<5 ms», «любой сайт» и «все форматы» требуют собственных файлов/повторов.

**Qwen-MM-Plugins**, [3657](https://t.me/vibecoding_tg/3657): набор multimodal plugins; README содержит manual path для OpenCode. Это конкретнее произвольного предположения о совместимости, но Windows/WSL, provider costs, качество и ZCode остаются неподтверждёнными.

### 4. Производство — разделено на классы

Подборка [4073](https://t.me/vibecoding_tg/4073) содержит **15 репозиториев**, каждый доступен на GitHub. Фотография действительно разделяет website / own footage / launch / short. Поэтому в реестре отдельно:

- **Монтаж существующего видео**: FreeCut, Hyperframes Student Kit, Motion Graphics.
- **Программный видеорендер**: HyperFrames, Remotion, Claude Motion Design и связанные workflows.
- **Промо/запуск продукта**: Brag, Product Launch Motion и другие launch kits.
- **Веб-анимация и принципы motion**: Motion, GSAP Skills, LottieFiles skill — не выдаются за полноценный video editor.
- **Объясняющие иллюстрации/UI/3D**: Anatomy (точное имя `wheresryan22/anatomy`), Stageshow, Screenshot-to-Code, StableGen, PixelFX.

У HyperFrames документированы standalone skills для OpenCode и Windows. У FreeCut существенны современные Chromium/WebGPU/WebCodecs и локальное browser storage. Remotion имеет специальную commercial/company licensing модель: нельзя записать все 15 проектов как «бесплатные MIT». License detection GitHub не распространяется на сторонние assets, модели, музыку или голоса.

**Tesseract**, [4042](https://t.me/vibecoding_tg/4042): в тексте адрес Mirage converters, но href ведёт в ChatGPT plugin. Сохранены оба свидетельства; не утверждается, что исходники/лицензия или рендер Premiere/AE без подписки проверены.

### 5. Звук — полезная измерительная процедура, не замена слуху

Посты [4121](https://t.me/vibecoding_tg/4121) и [4122](https://t.me/vibecoding_tg/4122): лицензированные музыка/SFX, beat grid, ducking, ebur128 именно на финальном MP4, кадры/волна возле событий и пять точек для проверки в наушниках. Полезно адаптировать к существующему монтажному/аудиостеку, а не ставить новый только ради поста.

`−16 LUFS` и `<−4 dBFS` — ориентиры автора, не обязательный стандарт всех платформ; sample peak dBFS не равен true peak dBTP. Для TTS также нужны произношение, ударение, естественность, паузы и localization review. ASR/back-translation и график волны этого не доказывают.

Openverse оставлен как источник поиска, а не гарантия отсутствия ключей/квот или прав на всё. Счётчики/лимиты из поста не проверены; license, attribution, источник и реальный файл проверяются по каждому результату. Фото при 4122 содержит sound-pass prompt, не документацию API.

### 6. Память, orchestration и безопасность — вспомогательный слой

OpenViking, Semantica, DAIR Wiki Builder, Matt Pocock skills, AnythingLLM/Dify/Sim и reference RAG courses не смешаны в один класс. Одна вещь — готовая wiki, другая — контекстная БД, третья — framework для самостоятельной разработки. OpenViking/Lightpanda имеют AGPL-условия; Dify — отдельную лицензию.

Orca/Herdr/AX/Buzz/OpenSandbox/TokenEconomizer оставлены как опции контроля/координации, **не обязательная новая архитектура**. DSH plugins из 4240/4263 сохранены по именам, но source links там отсутствуют: не выдумывались repos и не подтверждалась совместимость с другими оболочками. Нельзя устанавливать неизвестный `dsh-our-free-model` и отдавать туда confidential data только из-за слова free.

14 дополнительных Jev-проектов из 3920 сохранены отдельно как discovery backlog. Их существование, код и тарифы не проверены; названия вроде KillMyIdea не превращают их в подтверждённые инструменты проверки экономики ниш.

## Что архив не заменил

1. **Корпоративные/нативные источники широкого спроса** из основного реестра: Google/YouTube/TikTok/Pinterest/региональные поисковые и коммерческие инструменты. В этом экспорте больше production/agent tooling, чем независимых данных рынка.
2. **Доказательный отбор 5–7 ниш**: независимые сигналы, вопросы людей, существующие ответы/пробелы, экономика, язык/география и повторяемость оригинального производства.
3. **Мультиязычную редактуру** и проверку естественности голоса: English/Russian/Ukrainian/Greek проверяет владелец; для других языков нужен отдельный quality gate.
4. **Публикацию и аналитику**: законченный проверенный multilingual publishing workflow в архиве не установлен. ARTEMIS/commerce prototypes не равны готовому pipeline публикации.
5. **Локальные испытания**: первичные описания не результат запуска.

Ниши по личному аудиотехническому опыту владельца не сужались. Готовые решения не исключены в пользу собственного framework. Следующий шаг — [сопоставимые пробы по классам](TRIALS.md), а не установка всех кандидатов или новое плановое Deep Research.
