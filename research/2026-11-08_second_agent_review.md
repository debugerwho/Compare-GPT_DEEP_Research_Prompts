### Browser Use

Источник: https://github.com/browser-use/browser-use

README blob: `fe0d153c091192af376573013bf27974de9169ff`.

Документированы разные пути: CLI для существующего агента; Python-библиотека с выбором модели и локальным/облачным браузером; полностью размещённый API. В примере библиотеки модель вызывается через ключ; облачный браузер требует отдельного доступа. README отдельно объясняет, что бесплатная MIT-библиотека не означает бесплатный inference/hosting; возможна локальная модель при подходящем оборудовании.

Вывод: нельзя приписывать всем режимам одинаковые требования к ключам и подпискам. Не проверены ни точные модели владельца, ни качество их выполнения.

### Stagehand

Источник: https://github.com/browserbase/stagehand

README blob: `ccbe44ff7e0e789cc59fd25a26474913f38ee1b2`.

Документированы SDK, операции act/observe/extract, локальный браузер и облачные варианты. Для coding-агентов README предлагает `browse` CLI и skill; прямо заявлена локальная работа этого пути без LLM key и Browserbase account. Hosted MCP, напротив, требует Browserbase API key. ## Последствия для наших промптов

Большинство полезных требований уже есть в A/B: browser-first, GitHub/сообщества, зависимости, примеры, разные монетизации и маркировка непроведённых испытаний. Полная замена не нужна.

Точечное дополнение к A: названные три проекта — стартовые кандидаты, а не назначенные победители. Для каждого сравнивать CLI/skill, SDK и hosted MCP отдельно; проверять совместимость с возможностями агентной оболочки, а не одним названием модели. Работоспособность инструмента браузера и доказательность измерения спроса — два разных критерия.

Важная граница Deep Research: исследовательский запуск должен изучать репозитории и задокументированные примеры, но нельзя предполагать, что он способен установить эти инструменты или войти в кабинеты владельца. GPT Plus не следует считать подтверждением доступа к внешним модельным API или стороннему хостингу. Практический пилот выполняется отдельно в подходящей среде; невыполненная проверка остаётся невыполненной.
